# eBay hard rules (set by Joshua 2026-09-17 from store feedback) — Layer 6 facts

## eBay markdowns, offers, model numbers and precious metal
1. Markdowns on eBay listings start at 90 days aged, not 30.
2. Never turn Best Offer on, and never allow offers on video games.
3. Never delete a model number from a title just because it looks like an internal tracking code.
4. Never reprice precious metal (gold, silver, platinum, bullion, coins) on eBay at any age — the counter already prices it at melt.
