2. **No empty captions. Ever.** (45% of the audited 90 days had none.)
3. **No byte-identical text across platforms or pages.** Every account gets its own variant.

   is accessories, optics, safes and gear only.
5. **Community posts carry no CTA and no product.**
6. **A `[PATTERN]` date is never published as a date.**

## How this file is used
The weekly lane tasks read this for the season's hooks and the week's dated events;
`CITY_COMMUNITY_KB.md` supplies the per-town local truth; `creative_drift.py` decides which
*format* fills each slot. This file sets the **subject**, the drift engine sets the **treatment**,
and the KB keeps both honest.
