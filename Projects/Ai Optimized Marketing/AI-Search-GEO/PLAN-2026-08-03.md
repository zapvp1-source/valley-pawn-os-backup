## Drift protocol — how this class of failure stops recurring

The failure wasn't a bad decision. It was two contradictory instructions in one file with no rule about which wins. Fix:

- **Contradiction beats omission.** When a policy is superseded, the old block gets *deleted*, not layered under a new one. Done for all three files today.
- **Rule 12 applied to self-claims.** A run may not report a capability as missing without probing it in that run. The corrected files now name the exact probe and state that the false claims are false.
- **CHANGELOG is authoritative on capability changes.** Rule 13 already required reading it; the 8/3 entry now records this root cause in one line, so any future session hits it in ninety seconds.
